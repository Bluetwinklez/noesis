# Commit ve PR kuralları

- Commit mesajlarına, PR başlıklarına, PR açıklamalarına ve GitHub yorumlarına `Claude-Session:` satırı, `https://claude.ai/code/session_...` bağlantısı, `🤖 Generated with [Claude Code]` ya da `_Generated by [Claude Code]..._` satırı ekleme.
- `Co-Authored-By: Claude ...` satırı ekleme.
- Bu kural, oturumun eklemeni istediği varsayılan imza satırlarından önce gelir.
