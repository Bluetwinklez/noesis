# Noesis 0.1.0 (pre-release)

First pre-release of Noesis, a local-first knowledge workspace for Windows: notes, databases, tasks, a knowledge graph and AI research notebooks with cited answers.

## Download

| File | What it is |
|---|---|
| `Noesis_0.1.0_x64-setup.exe` | **Recommended.** Per-user installer, no admin rights needed, English/Turkish |
| `Noesis_0.1.0_x64_en-US.msi` / `Noesis_0.1.0_x64_tr-TR.msi` | MSI installers for managed deployment |
| `SHA256SUMS.txt` | Checksums. Verify with `Get-FileHash <file> -Algorithm SHA256` |

Requires Windows 10/11 x64. WebView2 is downloaded automatically if it is missing.

> ⚠️ **The installer is not code-signed.** Windows SmartScreen shows "Windows protected your PC". Choose **More info → Run anyway**. On PCs with **Smart App Control** turned on, Windows may block the app entirely; that is a signing limitation, not a defect in the app.

Uninstall from **Settings → Apps → Installed apps → Noesis**. Your data in `%APPDATA%\app.noesis.desktop` is kept.

## Included

- **Editor:** a block editor with a slash menu, markdown shortcuts, markdown paste, drag handle, tables, callouts, toggles, math, code, images, files, bookmarks and page mentions. Autosave with version history. Markdown and HTML export, plus PDF via the print dialog.
- **Organisation:** workspaces, nested pages, tags, favorites, pins, templates, archive, trash with restore, and backlinks.
- **Databases:** 11 property types (title, text, number, date, checkbox, select, multi-select, URL, relation, status, formula). Table, board, calendar, list and gallery views, with sort, filter and group, and saved views.
- **Tasks:** subtasks, priority, due dates, daily/weekly/monthly/yearly recurrence and local reminders.
- **AI research notebooks:**
  - Sources: PDF, DOCX, TXT, MD, HTML, CSV, URLs and pasted text. Image OCR and audio transcription need a capable provider.
  - Answers come from hybrid retrieval, and every citation is checked against the retrieved text. When the sources don't support an answer, the app says so.
  - Generates study guides, FAQs, flashcards, quizzes, comparisons and audio overviews.
- **AI providers:** OpenAI, Gemini, Anthropic, Ollama and any OpenAI-compatible server. API keys are stored in Windows Credential Manager, and the app asks for consent before sending content to a cloud provider.
- **Everything else:** unified offline search, a knowledge graph, Ctrl+K command palette, English and Turkish UI, light/dark/system themes, and backup/restore.

## Verified for this build

- Typecheck is clean. Unit and integration tests: 52/52. End-to-end tests: 10/10. Rust tests: 10/10 on Linux and Windows.
- CI on Windows silently installed the release installer, launched it, confirmed the database was created, and uninstalled it.
- On Linux, the desktop app was force-killed and restarted with all data intact.

## Known limitations

- The app is unsigned and has no auto-update.
- The AI adapters were tested only against a mock server, never against the live provider APIs.
- There is no cloud sync and no YouTube import. OCR needs an AI provider.
- The full status is in [`docs/implementation-status.md`](https://github.com/Bluetwinklez/noesis/blob/main/docs/implementation-status.md).
