# Noesis 0.1.0 (pre-release)

First pre-release of Noesis, a local-first knowledge workspace for Windows.

**Unsigned installer.** Windows SmartScreen will warn about an unknown publisher. Verify the download against `SHA256SUMS.txt`.

## Included
- Block editor with slash menu, markdown shortcuts, drag handle, tables, callouts, toggles, math, code, images, files, bookmarks and page mentions; autosave with snapshots; Markdown/HTML/PDF (print) export.
- Workspaces, nested pages, tags, favorites, templates, trash/restore, backlinks.
- Databases with 11 property types (title, text, number, date, checkbox, select, multi-select, URL, relation, status, formula); table, board, calendar, list and gallery views; saved views with sort, filter and group.
- Tasks with subtasks, priority, due dates, recurrence and local reminders.
- AI research notebooks: PDF, DOCX, TXT, MD, HTML, CSV and URL sources (image OCR and audio transcription with a capable provider); hybrid retrieval; verified citations; "not supported by sources" answers; study guides, FAQs, flashcards, quizzes and comparisons; audio overviews.
- Providers: OpenAI, Gemini, Anthropic, Ollama and any OpenAI-compatible server. Keys are stored in Windows Credential Manager. Per-provider consent is required before content is uploaded.
- Unified offline search, knowledge graph, Ctrl+K command palette, English and Turkish UI, light/dark/system themes, backup/restore.

## Known limitations
- No cloud sync, no auto-update, no YouTube transcript import (not supported, and reported as such).
- PDF export uses the system print dialog.
- AI adapters have been tested against a mock server only.
- See `docs/implementation-status.md` for the full list.
